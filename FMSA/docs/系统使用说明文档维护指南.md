# 系统使用说明文档维护指南

## 文档位置

系统帮助文档存放在：

```
fmsa_django/static/docs/system_guide.md
```

## 如何编辑

直接用 VS Code / Cursor 打开上述 `.md` 文件编辑即可。保存后刷新页面，点击帮助图标即可看到最新内容（无需重启服务）。

## 如何查看效果

1. 启动系统，打开主页
2. 点击标题右侧的 **?** 图标
3. 弹出说明文档窗口（markdown 渲染后的格式化内容）

## 如何插入图片

1. 将图片文件放入 `fmsa_django/static/images/` 目录
2. 在 md 文档中引用：

```markdown
![图片描述](/static/images/your_image.png)
```

## 常用 Markdown 语法

```markdown
# 一级标题
## 二级标题
### 三级标题

**加粗文字**
`代码片段`

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 值  | 值  | 值  |

> 引用块（用于注意事项）

- 无序列表
- 列表项

1. 有序列表
2. 列表项
```

## 注意事项

- 文档只需编辑 `system_guide.md` 一个文件，无需修改代码
- 如果系统在内网环境下运行，图片路径需使用系统静态文件路径（`/static/images/xxx`）
- 如需多页文档，可新建多个 `.md` 文件，并在 `index.html` 中扩展帮助按钮逻辑
